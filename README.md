-RECIPE Mania-

Welcome to RECIPE Mania, a modern digital platform designed for food lovers to discover, cook and share their favorite recipes.

This project is built for the ICT 1209 - Web Technologies module.

-Project Theme-

Theme: Digital Recipe Book

Our web application serves as a comprehensive digital recipe book. It includes features for recipe searching, dynamic filtering and a platform for users to submit their own recipes.

-Features-

This frontend implementation includes:
- Responsive Design: Fully responsive layout built with Bootstrap 5.
- Interactive UI: Modern card layouts, hover animations and a clean user interface.
- Form Validation: Real-time JavaScript validation for the Login and Recipe Submission forms (`assets/js/main.js`).
- Pages Included: Home, Recipes, Submit Recipe, and Login.

-Setup Instructions-
Since this is a static frontend web application, no complex server setup is required.
1. Clone the repository: `git clone https://github.com/WOTTW/ict-1209-mini-project`
2. Open the project folder.
3. Simply double-click `index.html` to open the website in your preferred web browser.
